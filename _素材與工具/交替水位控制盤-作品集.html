交替水位控制盤
配電盤製作與現場施工

公司承接的水位交替啟動控制盤專案,兩面盤(A盤／B盤)、四顆軟啟動器控制四顆抽水馬達,依電氣單線圖與控制圖完成元器件佈置與配線施工——是我目前獨立完成過最複雜的配電盤案例。

OMRON 61F-G4 水位偵測 SMC 軟啟動器 ×4 A/B 兩盤交替設計 單線圖／控制圖判讀 端子壓接與線號標示

OMRON水位偵測 + 繼電器保護

任務背景

儲水槽/給水槽交替抽水,缺水溢水都要防

這是公司承接的水位控制盤專案:透過 OMRON 61F-G4 無浮球水位開關(Floatless Level Switch)偵測儲水槽與給水槽的水位,控制四顆抽水馬達交替啟動抽水,並在缺水(LL)、溢水(LH)時觸發警報與保護動作。四台馬達搭配 SMC(Soft Start Pump Motor Controller)軟啟動器,避免馬達啟動瞬間電流衝擊。

整組控制迴路依負載拆成 A盤／B盤 兩面盤(圖面標示 EPA／EPB),我負責的是依公司提供的單線圖與控制圖,精確完成兩面盤內部的元器件佈置、繼電器與軟啟動器配線、端子壓接與線號標示。電路設計由公司圖面部門完成,我的角色是把圖面**準確、安全地變成實體盤**——這正是「照圖配盤」現場實務的核心能力。

公司承接的盤子裡有些迴路規模更大,但多是重複同一種接法;這面盤的 A/B 交替、互鎖(EX)邏輯變化較多,是我目前實際完成過**邏輯複雜度最高**的案例,不是元件數量最多的一個。

施工重點

從讀圖到成品,四個關鍵環節

圖面判讀

看懂 EPA/EPB 交替邏輯與繼電器連動

控制圖上 X1~X4、R1~R4 等繼電器彼此連動,搭配 ON/OFF 按鈕與 EX(互鎖)迴路,決定兩面盤何時交替啟動、何時互相鎖定;施工前要先讀懂整份圖的邏輯關係,才不會接錯線。

  • 單線圖 + 控制圖對照判讀
  • EPA／EPB 交替控制迴路邏輯
  • ON/OFF、互鎖(EX)迴路關係確認
元器件佈置與配線

OMRON 繼電器組 + 水位開關 + 軟啟動器

盤內佈置 OMRON 61F-11 繼電器組與 61F-G4 水位開關,搭配四組 SMC 軟啟動器(SOFT START PUMP MOTOR CONTROLLER)控制四顆馬達;所有配線依線號標示逐一壓接,確保盤面整齊、日後維護好追蹤。

  • OMRON 61F-11 繼電器 + 61F-G4 水位開關佈線
  • SMC 軟啟動器 R/S/T、U/V/W 動力配線
  • 端子壓接、線號標示,盤面整齊可追蹤
保護迴路

缺水、溢水、過載都要有保護動作

儲水槽/給水槽各設缺水(LL)、溢水(LH)偵測點,搭配過載保護(OL1~OL4)與警報繼電器(R1~R4,MY2N),任何異常狀況都要能正確觸發保護、不誤動作也不漏動作。

  • 儲水槽／給水槽缺水、溢水偵測點配線
  • OL1~OL4 過載保護迴路
  • R1~R4 警報繼電器(MY2N)配線
送電前測試

接完不是結束,通電確認才算數

配線完成後依圖面逐點檢查、量測迴路是否正確,再進行送電前測試,確認各繼電器動作、馬達運轉方向與保護迴路都符合設計,現場除錯排除配線異常。

  • 迴路量測與逐點檢查
  • 送電前測試、動作確認
  • 現場除錯,排除配線異常
